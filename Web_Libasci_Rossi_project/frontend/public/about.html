Chi siamo — Stasera

Stasera è la piattaforma web dedicata alla scoperta di eventi, serate, locali e musica nella tua città.

Progettata per rendere semplice e immediato trovare cosa fare questa sera, l'applicazione combina una mappa interattiva alimentata da Google Maps con un sistema di filtraggio per data e posizione.

Caratteristiche principali

  • Mappa interattiva integrata con le API di Google Maps.
  • Filtro eventi per oggi, domani, weekend e posizione geografica.
  • Autenticazione rapida e sicura tramite Google OAuth 2.0.
  • Gestione della sessione utente per salvare eventi preferiti.
  • Architettura backend modulare suddivisa in layer con responsabilità singola.
